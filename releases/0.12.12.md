# TensorTonic 0.12.12

Adds a separately invoked saved-session diagnostic that performs at most one fixed account GET without modifying local session data, reconnecting, importing, clearing, adopting response cookies or grading. The API exposes only bounded diagnostic enums, booleans and a request count. The updated native runner requires an already active extension with this API and never falls back to ordinary session operations.

Cloud validation passed 896 aggregate tests, 152 session checks and 91 transport checks. All 57 new regression tests passed independent review. Package allowlist, archive integrity and source-byte parity passed.

Local preservation does not guarantee remote session non-mutation. Set-Cookie responses remain unverified. Optimistic snapshot checks cannot atomically stop a request if another process changes or clears the session immediately before dispatch; detected changes invalidate the result. No automatic replay occurs.

No native installation, real-account validation, new Focus pixel evidence or live grading is claimed. Earlier 0.12.11 artifacts are preserved.
