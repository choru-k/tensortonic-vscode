# Icon provenance and licensing

The bundled icon derives from TensorTonic's published
[favicon](https://www.tensortonic.com/images/logos/favicon.svg). Its source geometry
is the TensorTonic dolphin silhouette with a T-shaped interior. Attribution here
does not imply affiliation, endorsement or a license grant.

## Included assets

- `media/tensortonic.svg` is a monochrome 24×24 activity-bar adaptation. The source
  path geometry is unchanged; the background is removed and the silhouette is
  uniformly centered. Native theme foreground supplies its color.
- `media/tensortonic-icon.png` is a 256×256 full-color rasterization for the extension
  listing and VSIX icon metadata.

The extension's name remains **TensorTonic for VS Code (Unofficial)**. Website content,
trademarks and this brand asset belong to their respective owners.

**Reuse rights remain unresolved.** No explicit reuse license was found in the
supplied favicon. The repository's MIT license covers its code and does not grant
rights to the TensorTonic logo or brand asset. Including attribution or publishing
this extension does not resolve that separate licensing question.

Selected theme smoke checks cover the reviewed activity-bar and UI surfaces; they
do not establish appearance at every scale, state or extension-listing surface.
Website screenshots, downloaded website HTML and preview helpers are not packaged.
